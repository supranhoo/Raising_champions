## Requirements

### R1. Brand Identity & Design System Alignment (Optra360 / Zoptro)
- Fully adopt the brand expression system:
  - Display Font: Outfit (Bold / SemiBold / Medium)
  - Functional / Body Font: Figtree (Regular / Medium / SemiBold)
  - Color Palette: Progress Orange (#F65800), Grounded Olive (#666D57), Clarity Ivory (#F4F2EA), Authority Blue (#09293D), Slate/Secondary neutrals (#1C5682, #D9E6EB, #DED9D3, #F9F8F3, #000000, #FFFFFF).
  - Strict Geometric Construction: 90° square edges, zero border-radius (rounded-none), no decorative neon glow or cyber gradients, solid flat surface cards with generous padding, left-aligned typography by default.

### R2. Dual-User Authentication & Account Pairing
- Implement distinct Sign-Up and Sign-In flows for Student and Parent.
- Support PIN and password access with session persistence (client-side storage + backend session validation).
- Establish parent-student pairing mechanism (family pairing code / invite key generated by parent during sign-up).
- Enforce parent-exclusive governance: only the paired parent can alter student allowance/coins, approve quests/redemptions, modify daily tasks, change passwords, and configure limits.

### R3. Strict Verification & Customized User Interfaces
- Student Portal:
  - Focus Dashboard: Daily Quest checklist, streak tracker, Focus Coins & XP wallet, Level progression.
  - Interactive GK Arena & Study Sprints: Practice quizzes and focus timers with automatic reward queuing.
  - Rewards Catalog: Student can browse available rewards and submit redemption requests to the parent.
- Parent HQ (Control Hub):
  - Strict Verification Queue: 1-click approval/rejection for completed student quests and reward redemptions before coins/XP are awarded.
  - Quest & Habit Management: Add, edit, archive habits, customize coin/XP values.
  - Account Controls & Security: Manage student PIN/password, set study schedules, view audit trails.
  - Comprehensive Analytics & Reporting: Weekly activity logs, streak summaries, and one-click email digests.

### R4. Dual-Mode Backend & Google Sheets Integration
- Google Sheets database schema with automated initialization: Users, HabitsQuests, SubmissionsQueue, RewardsCatalog, RedemptionsQueue, ActivityLogs.
- Complete backend API in google_apps_script_backend.js with role-based validation.
- Built-in local browser mock fallback allowing immediate interactive testing without needing live deployment.
